# Assignment 4 - Final Assessment

## Format

The final assessment is similar to a practical interview question. You'll be given a dataset and a set of questions to answer about it, and a fixed window of time to build a visualization that answers them. This mirrors what you'd be asked to do in a real technical interview for a front-end or data-viz-adjacent role.

You'll receive the dataset and prompt from your instructor when you're ready to sit the assessment — talk to your co-working group / instructor once Assignment 2 (your three visualizations) is done.

## What you'll be expected to do

- Load and inspect an unfamiliar dataset quickly
- Identify what questions the provided prompt is actually asking
- Choose an appropriate chart type for the data and the question
- Build a working visualization within the time window, using any of the techniques covered in the [lessons](../lessons): HTML/CSS/JS, Canvas, SVG, or D3
- Explain your approach and your code

## How to prepare

- Make sure you're comfortable with the full data pipeline: load → clean/filter/sort → map to visuals → draw
- Review [lesson-12](../lessons/lesson-12.md) and https://www.data-to-viz.com so picking a chart type is fast, not a bottleneck
- Practice building a small chart from an unfamiliar dataset against a timer

## Evaluating your work

| Aspect | Does not meet | Meets | Exceeds |
|:-------|:--------------|:------|:--------|
| **Correctness** | The visualization doesn't answer the questions asked, or the data is misread | The visualization correctly answers the questions asked | The visualization answers the questions and reveals something the prompt didn't explicitly ask for |
| **Chart choice** | Chart type is a poor fit for the data | Chart type suits the data and question | Chart choice actively makes the story easier to see |
| **Code quality** | Doesn't run, or is unreadable under time pressure | Runs, reasonably organized | Clean enough that you could hand it off mid-interview |
| **Communication** | Can't explain the approach taken | Can explain the approach and tradeoffs made | Can explain alternative approaches and why this one was chosen |
