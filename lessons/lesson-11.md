
# ACS 4310 - D3 Scales

## Overview

Scales are how D3 maps values from your data (a domain) onto values you can draw with — pixels, colors, radii (a range). This is the same normalization idea from Canvas ([lesson-06](./lesson-06.md)), formalized as a reusable D3 API.

## Learning Objectives

- Use `d3.scaleLinear`, `d3.scaleOrdinal`, and `d3.scaleBand` to map data to visuals
- Explain the difference between a scale's domain and its range
